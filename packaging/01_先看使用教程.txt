彩票选号工具 0.10.0｜新电脑使用教程
适用：Windows 10 / 11，Intel 或 AMD 的 64 位电脑。
不支持 Windows 7、32 位系统、macOS。ARM 电脑未验证。
建议为压缩包和解压后的文件预留至少 3 GB 空间。

本包已内置 Python、训练依赖、五种彩票的历史数据和现有模型。
不需要另装 Python、pip、CUDA、办公软件或开发工具。
网页使用 Windows 自带的 Edge 或您自己的默认浏览器。
如果新电脑缺少微软运行组件，可用包内的微软安装包离线安装。

第一步：复制压缩包
1. 把完整 ZIP 复制到新电脑。
2. 不要在压缩包里面直接双击启动文件，也不要只复制一个启动文件。

第二步：全部解压
1. 右键 ZIP，选择“全部提取…”。
2. 选一个路径较短的位置，例如 D:\LotteryTool；没有 D 盘可选择其他可写的短路径。
   不建议放进“Program Files”，也不要连续套很多层文件夹。
3. 等待全部解压完成，打开解压后的 LotteryTool-0.10.0-Win64 文件夹。
4. 应能看到：
   01_先看使用教程.txt —— 本教程
   Start.bat          —— 双击启动
   Check.bat          —— 双击检查文件和环境
   app                —— 程序、数据、模型及结果
   runtime            —— 内置 Python 和依赖，请不要修改
   installers         —— 微软运行组件安装包
   logs               —— 运行日志（首次运行会自动创建）

第三步：第一次先做环境自检
1. 双击 Check.bat，等待出现“自检全部通过”。
   首次检查文件较多，可能需要一两分钟；速度取决于电脑和磁盘。
2. 如果出现 MSVCP140、VCRUNTIME 或 Microsoft Visual C++ 运行库缺失：
   先关闭错误窗口，打开 installers，双击 VC_redist.x64.exe。
   确认安装程序发布者为“Microsoft Corporation / 微软”，按提示安装；
   如果要求重启，先重启，再重新双击 Check.bat。
   这个微软安装包已随 ZIP 附带，不需要另上网寻找。
3. 如果自检通过，就不用安装任何东西。
4. 如果是其他错误，不要盲目重复安装，也不要关闭安全防护。
   请保留报错截图及 logs 文件夹，交给维护者检查。

第四步：启动
1. 双击 Start.bat。
2. 等待浏览器自动打开，使用期间不要关闭启动时的黑色窗口。
3. 浏览器没有自动打开时，在 Edge 地址栏输入黑色窗口显示的地址。
   一般为 http://127.0.0.1:7861，若端口占用会选其他本地端口，以窗口显示为准。
4. 不需要注册或登录账号；页面运行在您自己的电脑上，不是互联网网站。
5. 停止时，回到黑色窗口按 Ctrl+C，再关闭窗口。仅关闭浏览器不会停止程序。
   避免反复双击启动多个副本。

第五步：直接使用组合选号（最简单，不需要训练）
1. 默认打开“组合方案与中奖概率”页。
2. 选择双色球、大乐透、排列3、排列5或7星彩，并选择对应玩法。
3. 保持默认“均匀去重”方案，填写希望生成的注数，点击生成按钮。
   默认10注；一注是一整组号码，不是一个数字。请同时看清页面显示的成本。
4. 需要时可改为目标奖级覆盖方案；这种组合优化也是本地计算。
5. 使用页面“复制”或“导出”按钮保存结果。
   组合导出保存在 app\results\portfolios；旧预测记录在 app\results\predictions。
6. 以上无需历史数据更新，也无需网络。模型排序模式则要先完成下面的训练步骤。

第六步：想使用模型，再按顺序训练
1. 选择彩种和玩法，进入“分步操作”页。
2. Step 1：联网更新用“获取/更新数据”；离线直接点“读取本地数据（不联网）”。
3. Step 2 点击“开始训练”；初次保持已经填好的默认参数即可。
4. 等待出现“模型训练完成”，然后在 Step 3 生成号码；
   或回到“组合方案与中奖概率”页选择模型排序模式。
5. 也可用“一键选号”，它会依次获取数据、训练、生成号码。
6. v0.8训练后会保存可校验的训练档案。下次重启，在“分步操作”点击
   “恢复已保存模型（不重训）”，数据和权重一致即可继续选号，不用再次训练。
   恢复使用的是档案记录的参数，不是当前滑块的值。
   如果在线更新过数据或权重发生变化，会拒绝恢复，请重新训练。
   v0.7等旧版本没有训练档案，升级后需先训练一次；不能凭旧权重猜测档案。
7. 训练会更新本副本 app\models 内的模型/缩放器。
   如果想保留旧模型，请在训练前先复制备份 app\models。
8. 不同电脑训练速度不同；卡住时先看黑色窗口，避免连续点击。

断网时能做什么？
- 组合选号、组合覆盖、号码复制和导出可以离线使用。
- 五种彩票的历史数据已经在 app\data 中。
- 点击“读取本地数据（不联网）”可直接使用随包历史，不等待联网超时。
  随后可以离线训练、保存档案、重启恢复和生成号码。
  离线流程已做应用层断网模拟验证；仍可保留“获取/更新数据”的联网尝试及失败回退。
- 更新到新的开奖数据仍需要联网，而且依赖第三方开奖网页是否可访问。
- 包内历史数据只是快照；请查看页面“最新期号/日期”。过期提示并不等于程序损坏。
- 旧数据生成的结果不是已经获取了最新开奖信息，不能当作最新一期数据的保证。

如何备份和再次换电脑？
1. 先停止程序。
2. 把整个解压文件夹复制一份最省心；至少备份 app\data、app\models、app\results。
3. 最初 ZIP 只保存打包时的数据，不会自动包含您后来训练和导出的内容。
   app\models 内的 *_training_session.json 是恢复档案，应和权重一起备份，不要单独改动。
4. 第二次换电脑时，应复制使用后的完整文件夹，或先部署原 ZIP 再恢复自己的上述备份。
   恢复前先把新电脑同名文件夹另存备份，避免覆盖错文件。

新增：预测优势验证（研究用途，不是购票服务）
1. 打开“预测优势验证”，点击“查看历史实验与所需样本量”。
   包内包含固定参数、最后300期的历史对照，不能当作开奖前预测证据。
2. 点击“冻结本轮前瞻实验”。已有协议时只检查，不会覆盖或重置。
   七种玩法、每期5组实验号码、每种玩法1000个登记目标期固定不变；不代表推荐购买量。
3. 先联网更新数据并核对，再填写下一期的五位期号和官方开奖日期。
   点击“生成并锁定模型组与随机对照”，同一目标期不允许重复提交。
   当前保守地只接受明天或以后的日期，不支持跨年首期。
4. 开奖后更新数据，点击“开奖后读取本地数据核验”。
   未来未开奖、数据缺失或期号日期冲突都不会被冒充为已完成样本。
5. 实验、独立研究模型及记录位于 app\evidence_runs；换电脑时也要完整备份该目录。
   不要修改其中冻结算法/模型档案，不要只保留中奖记录。
6. 本地哈希链能检查意外改动，不是不可篡改的第三方开奖前时间戳。
   真正独立核验还需提前由独立方保存协议和原始记录；本软件不会自动上传。
7. 1000期不是足以证明所有彩种优势的承诺。头奖极罕见，所需验证期数可能非常大。
   不需要为实验实际购买彩票，全部可以只记录和计算。

新增：国际算法对照（不会替换旧模型）
1. 打开“国际算法对照”，点击“查看最新完整对照”，直接查看随包的实验结果。
2. 页面并列显示XGBoost、简单马尔可夫、冻结LSTM和均匀随机的七种玩法成绩。
   每种方法每期5组，测量的是最高奖命中期数；不是购买建议。
3. 展开偏差诊断或辅助概率诊断可查看详细指标，它们不能被当成一等奖中奖率。
4. 若要重现，点击“运行固定参数实验”。首次可能需要十几分钟，耗时取决于CPU；
   请保留启动窗口。本轮仅使用随包的旧研究快照，不联网更新、不覆盖旧研究。
5. 新结果独立保存在 app\candidate_runs；重复计算同一历史不增加独立证据。
   换电脑时也要完整备份这一目录。新候选尚未接入未来前瞻登记，不自动成为默认算法。

常见问题
- 窗口一闪而过：先确认已“全部提取”，再双击 Check.bat。
- 本地网页打不开：确认启动窗口仍在，地址与窗口一致；不要同时运行多个副本。
- 提示“请先获取数据/训练”：依次完成分步操作的 Step 1、Step 2。
- 运行目录无法写入：把完整文件夹放到自己可写、路径较短的位置。
- 在线数据更新失败：检查网络；第三方网页也可能暂时不可用。本地组合选号仍能使用。
- 文件被安全软件拦截：不要关闭防护或下载替代 DLL，保留提示并联系维护者。
- 不要自行升级 runtime 里的组件，不要用其他 Python 打开程序。

验证范围
发布时已执行包内环境检查和本机迁移验证；这不等于在您的新电脑或全新 Windows 虚拟机上验收。
Check.bat 用于检查意外缺失/损坏及运行能力，不是数字签名或安全软件的替代品。

重要提醒
本工具用于选号、组合覆盖及历史/模拟对照，未证实模型能提高真实一等奖预测率。
最高奖组合概率、小奖模拟结果和模型分数不是中奖保证；增加注数也会增加成本。
