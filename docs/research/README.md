# 研究流程与复现范围

研究不需要实际购买彩票。公开仓库保留方法与[旧实验汇总](v0.10.0-results.md)，不附私人快照、模型、预测记录或冻结协议。没有原始数据与工件，不能声称独立重现旧实验的每一个数值。

## 使用自己的数据建立新研究

1. 按[使用指南](../../使用说明.md)准备五彩种的合法历史。检查来源、规则、重复期号与日期；不要把已查看数据称为未来样本。
2. 使用README中的同一Python环境，在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -X utf8 -B run_evidence_experiment.py --n-test 300
```

这会创建独立`evidence_runs/<时间戳>/`，以训练前缀重训LSTM并将末端300期留作历史比较；需要足够历史和CPU时间，不覆盖原模型。

3. 打开界面“预测优势验证”，冻结研究方案。该流程是候选实验读取基准研究的前提；不得修改已冻结代码、快照或权重。如果已有研究，它不会自动选择成绩最好的一份。
4. 在“国际算法对照”运行固定参数实验，或使用：

```powershell
.\.venv\Scripts\python.exe -X utf8 -B run_candidate_experiment.py
```

新研究写入`candidate_runs/`，参数固定，比较LSTM/随机的号码是否与基准归档一致，再运行XGBoost/Markov。研究使用相同数据不是新增独立证据，不能靠重复运行提高统计可信度。

5. 通过界面读取完整结果。脚本读取报告时应使用`candidate_results.read_report`；冻结运行器内部旧读取辅助函数保留原样，Windows路径兼容由独立读取层处理。

## 前瞻与证据边界

现有未来登记针对冻结研究模型，并未接入XGBoost/Markov多模型未来比较。只登记开奖前真实生成的下一目标期，不补录过去，不只保留中奖期，不根据中途结果改参数或延长到显著。

本地记录不能独立证明生成时间，哈希链也不能防整链重写。需要独立方事先保存协议和记录，才可能加强时间可信度；本程序不自动上传、认证、购买或定时追踪。

每玩法1000期的固定观察上限不等于足够检验极罕见一等奖。任何新增模型比较均需事先定义检验家族、样本量、停止规则及真实未见数据。
